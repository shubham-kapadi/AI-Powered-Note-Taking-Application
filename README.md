# 🧠 AI Powered Note Taking System

An all-in-one productivity web application built during Technovate’26 Hackathon.  
This project helps users create, manage, and enhance notes using AI-powered features.

---

## 🚀 Features

- 🧠 AI-based Note Summarization  
- 🎤 Voice Assistant for Note Creation  
- 📝 Markdown Support  
- 📊 Flowchart Creator  
- 📄 Resume Builder  
- 📅 Calendar Integration  

---

## ⚙️ How to Run Locally

```bash
git clone https://github.com/shubham-kapadi/AI-Powered-Note-Taking-Application
cd AI-Powered-Note-Taking-System

# Install dependencies
npm install

# Run backend
node backend/app.js

# Run frontend (if using Vite)
cd frontend
npm install
npm run dev
